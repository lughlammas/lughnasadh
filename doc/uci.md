# UCI surface

Supported (core):

* `uci` / `uciok`
* `isready` / `readyok`
* `ucinewgame`
* `position startpos | fen ... [moves ...]`
* `go depth N | movetime N | wtime/btime/winc/binc | infinite | perft N`
* `stop`
* `quit`
* options: Hash, Threads (1), Move Overhead, Clear Hash

See INSTALL for a one-liner smoke test.
