# Freeness (software livre)

Lughnasadh aims to behave as **native free software** in the progressive
GNU sense of *freedom*, not price:

0. Freedom to run the program for any purpose (with the house ethical limit below).
1. Freedom to study how it works and change it (full C++ sources).
2. Freedom to redistribute copies.
3. Freedom to distribute modified versions.

Legal vehicle: **MIT License** (`LICENSE` / `COPYING`). MIT is a
permissive free-software license recognized by the FSF and OSI.

## Progressive / international posture

* Prefer open formats and UCI (an open protocol for chess engines).
* Prefer reproducible builds via CMake.
* Prefer honest strength claims (classical engine; not Stockfish/NNUE).
* Prefer documentation that a stranger can follow without tribal lore.

## Ethical constraint (house)

Even free software can be misused. In this house:

* Allowed: study, training, post-game analysis, GUI integration (Sherlock).
* Not allowed: live engine assistance in official rated championships.

Freedom to run does not erase responsibility.
