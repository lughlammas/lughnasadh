Lughnasadh 0.2.0 Second Harvest — motor UCI para Android
========================================================

Arquivo: Lughnasadh-0.2.0-arm64.apk
ABI: arm64-v8a (aparelhos 64-bit modernos)

Instalação no DroidFish
-----------------------
1. Copie o APK para o telefone (Downloads, Drive, cabo USB, etc.).
2. Abra o APK e permita instalar de fontes desconhecidas se o Android pedir.
3. Instale o pacote "Lughnasadh Engine" (com.lughnasadh.engine).
4. Abra o DroidFish → Menu → Motores (Engines) → escolha
   "Lughnasadh 0.2.0 Second Harvest" (ou atualize a lista de motores).
5. Se o motor não aparecer: Menu → Gerenciar motores / Importar, e aponte
   para o motor instalado via provedor Chess Engine.

Instalação no Chess for Android
-------------------------------
1. Instale o APK como acima.
2. No Chess for Android, abra a lista de motores UCI.
3. Selecione "Lughnasadh 0.2.0 Second Harvest" (liblughnasadh.so, arm64-v8a).

Notas
-----
- APK assinado com keystore de desenvolvimento (debug). Para atualizar no
  futuro, use a mesma keystore ou desinstale a versão anterior antes.
- Apenas arm64-v8a. Aparelhos só 32-bit (armeabi-v7a) não são suportados
  neste pacote.
- Uso: análise e treino clássico via protocolo UCI — sem rede, sem trapaça.
- Em caso de "app não instalado": confira se o telefone é 64-bit e se a
  instalação de APKs externos está liberada.

Assinatura: apksigner v1 + v2 + v3 (keystore debug Lughnasadh / Lughlammas).
