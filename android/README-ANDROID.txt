Lughnasadh 0.4.0 Fourth Harvest — Android source notes
====================================================

The source includes optional arm64 build and legacy engine-APK packaging helpers.
See README.md in this directory for prerequisites and commands.

No 0.4.0 APK release is included or verified by this consolidation. An external
reference APK skeleton is required for the packaging helper. Configure Android
NDK and signing credentials locally; do not commit them or generated APKs.
